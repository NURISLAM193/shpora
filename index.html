📘 Шпаргалка по HTML и CSS

Для студентов 2 курса (веб-дизайн)

1. Основные HTML-теги

Семантические теги

Тег Назначение
<header> Шапка сайта или секции
<nav> Навигация
<main> Основное содержимое
<section> Логическая секция
<article> Новость, пост
<aside> Боковая панель
<footer> Подвал сайта

Формы

<form>
  <label for="name">Имя:</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="email">

  <input type="submit" value="Отправить">
</form>

2. Основные CSS-свойства

Box Model

width → padding → border → margin 

.box {
  width: 200px;
  padding: 10px;
  border: 2px solid #000;
  margin: 20px;
  box-sizing: border-box; /* Важно! */
}

Display

Значение Описание
block Блочный элемент (новая строка)
inline Строчный (внутри текста)
flex Гибкий макет
grid Сеточная верстка

Flexbox

.container {
  display: flex;
  justify-content: center;    /* горизонталь */
  align-items: center;        /* вертикаль */
  gap: 10px;
}

Grid

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 10px;
}

Позиционирование

position Описание
relative Относительно своего места
absolute Относительно родителя
fixed Фиксировано на экране
sticky Липкий при скролле

3. 🌈 Дополнительные CSS-примеры

🎨 Изменение цвета фона

/* Цвет фона элемента */
.header {
  background-color: #3498db;
}

/* Градиентный фон */
.banner {
  background: linear-gradient(45deg, #ff7e5f, #feb47b);
}

/* Фоновое изображение */
.hero {
  background-image: url("bg.jpg");
  background-size: cover;
  background-position: center;
  background-attachment: fixed; /* фон "прилипает" при скролле */
}

📏 Интервалы: между буквами, словами, строками

.text {
  letter-spacing: 2px;     /* расстояние между буквами */
  word-spacing: 4px;       /* расстояние между словами */
  line-height: 1.6;        /* высота строки (межстрочный интервал) */
}

Пример:

letter-spacing: 1px; → "H e l l o" word-spacing: 10px; → "Один Два Три"

✨ Тени и скругления

.card {
  box-shadow: 3px 3px 15px rgba(0, 0, 0, 0.2);
  border-radius: 12px;
}

.text-shadow {
  text-shadow: 1px 1px 3px rgba(0,0,0,0.3);
}

🔄 Псевдоклассы (например, при наведении)

button {
  background: #3498db;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  transition: 0.3s; /* плавная анимация */
}

button:hover {
  background: #2980b9;
  transform: scale(1.05); /* увеличение при наведении */
}

📏 Размеры: единицы измерения

Единица Описание
px Пиксели (фиксированный размер)
% Процент от родителя
em Относительно шрифта родителя (1em = текущий размер)
rem Относительно корневого (html) шрифта
vh, vw 1% от высоты/ширины окна

4. Адаптивность (медиа-запросы)

/* Мобильные устройства */
@media (max-width: 768px) {
  .container {
    flex-direction: column;
    padding: 10px;
  }
  nav ul {
    flex-direction: column;
  }
  .text {
    font-size: 14px;
    line-height: 1.5;
  }
}
